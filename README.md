# Практическая работа 4

PHP-приложение: таблица сотрудников из CSV с фильтром по отделу и форма заявки.

## Запуск

Нужен PHP 8 с расширением mbstring (в php.ini строка `extension=mbstring`).

```
php -S localhost:8000 -t public
```

Открыть http://localhost:8000

## Структура

- `public/index.php` — страница
- `src/functions.php` — функции
- `data/` — файлы из dataset

После шага 12 чтение CSV и проверка формы вынесены в функции `loadEmployees` и `validateInput`.
После шага 13 таблицу можно отфильтровать по отделу (`?department=Разработка`), без параметра показываются все.

## Проверка (form_cases.json)

- пустое имя → «Укажите имя»
- стаж -2 → «Стаж от 0 до 50»
- Иван, стаж 4 → «Заявка принята»

## GET и POST

GET — данные в адресной строке, используется для фильтра.
POST — данные в теле запроса, используется для формы.

## htmlspecialchars

Превращает `<` и `>` в текст, чтобы введённый HTML не выполнялся.

## Путь данных

Форма → POST → `trim` → `validateInput` → ошибки или «Заявка принята» → вывод через `htmlspecialchars`.
